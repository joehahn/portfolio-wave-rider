Parameter sweep: max_watchlist_size

Unlike the three optimizer-knob sweeps, this one re-fires the curator at each cap value because the cap shapes the curator's decisions, not just the optimizer's response. Each curve is a separate curator-driven walk-forward over the same post-COVID window (2022-03-31 to 2025-10-31, 15 quarterly calls) the other three sweeps use, with starter watchlist [AAPL, MSFT, GOOGL, NVDA, SPY] and only the max_watchlist_size input changing. All other optimizer knobs are held at their investor_profile.md defaults, so the curves are directly comparable to the other sweeps. cap=5 is the project default (bolded).
