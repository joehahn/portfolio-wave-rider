These knobs touch only the mean-variance replay, not the curator, so the whole grid costs $0 (no LLM). Ranked by Information Ratio (annualized active return ÷ tracking error vs SPY — consistency of beating the benchmark). SPY returned +85% over the window. ★ = best in column.

All in-sample. These rank candidate configs to forward-test; they don't prove an optimum. Read the IR t-stat (|t|>2 ≈ real vs luck), the bootstrap CI (error bar on annualized return), and H1/H2 stable (does the edge hold in both halves) before trusting any row.
