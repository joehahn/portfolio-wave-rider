2. Frontier — return vs L1 churn / turnover (color = IR, red ring = current config)

Same configs, risk axis replaced by L1 churn = annualized one-way turnover (%/yr): how much of the portfolio is traded per year (Σ|Δweight| from share changes; drift between rebalances is not a trade). 100%/yr = the whole book turned over once a year. This is the industry-standard churn measure. Trading is free in an IRA, so read it as stability/robustness, not cost: lower churn = less noise-chasing / less overfit, so upper-left (high return, low churn) is the sweet spot. Current config: 1572%/yr.

3. Frontier — return vs L2 course-correction (color = IR, red ring = current config)

Same idea, but churn is the L2 (Euclidean) path length the portfolio was dragged along through weight-space (√Σ Δweight² per rebalance, summed & annualized) — your “total course-correction”. Vs L1, it weights concentrated single-name rotations more heavily. It ranks these configs almost identically to L1 (correlation 0.99), which is the useful takeaway: the two norms agree, so the churn ordering is robust. Current config: 1936/yr.

ann CI [5,95] — block-bootstrap 5–95% confidence interval on the annualized return (the error bar).
H1/H2 stable — whether IR > 0 in both halves of the window (a yes means the edge isn't a one-half artifact).
