1. Return vs drawdown

Each point is one cap/λ/lookback config; color = max_watchlist_size (2, 3, 4, 5, 6, 7, 8, 10, 12 shown), so every watchlist size contributes its own 150-config cloud (total 1350 points). Within a cloud the free knobs move a point deterministically; jumping between colors ALSO swaps the underlying curation, and those kimi re-curations swing 2-5× on their own — so read cross-color separation as parameter effect + curation-draw noise, not a clean mws response. The canonical live watchlist (3, ★) carries the red-ringed current config.

2. Return vs L1 churn

Same points (all watchlist sizes), risk axis replaced by L1 churn = annualized one-way turnover (%/yr): how much of the portfolio is traded per year (Σ|Δweight| from share changes; drift between rebalances is not a trade). 100%/yr = the whole book turned over once a year. This is the industry-standard churn measure. Trading is free in an IRA, so read it as stability/robustness, not cost: lower churn = less noise-chasing / less overfit, so upper-left (high return, low churn) is the sweet spot. Current config: 615%/yr.

3. Return vs L2 course correction

Same idea, but churn is the L2 (Euclidean) path length the portfolio was dragged along through weight-space (√Σ Δweight² per rebalance, summed & annualized) — your “total course-correction”. Vs L1, it weights concentrated single-name rotations more heavily. It ranks these configs almost identically to L1 (correlation 0.99), which is the useful takeaway: the two norms agree, so the churn ordering is robust. Current config: 815/yr.

4. Recommended settings

Read straight off plots 1-3: keep only configs in the safe corner — |maxDD| < 45% AND L1 < 750 AND L2 < 1000 (shallow drawdown, low churn on both norms). 143 of 1350 configs survive (by watchlist size — 2:53, 3:61, 4:7, 5:4, 6:11, 7:6, 8:1), listed once, sorted by IR. ★ = best in that column among the survivors, so you can eyeball the top IR / t-stat / Sharpe / Calmar / ann / shallowest-DD without re-sorting. 11. Rationale-soundness — blind judge (leak-free)

Every backtest column above (return, IR, Sharpe, Calmar, t-stat) is in-sample — the curator could have memorized which 2023–2026 names later won, so those numbers can't honestly rank reasoning. This section does: an independent judge (claude-opus-4-8, not one of the curators) reads each add/remove blind — model identity stripped, decisions shuffled, and the ticker's later price never shown — and grades only whether the stated rationale + cited news justified the call at the time. Five criteria (each pass/fail) + a holistic overall 1–5. 72 decisions judged, ~$0.58. Ranked by mean overall — this is the one ranking here that owes nothing to hindsight.
