Note on sources: the forward pull runs Anthropic WebSearch on the wave keywords with the news_sources.md source_block list passed as web_search blocked_domains, so the low-signal / PR-mill domains the backtest also drops are excluded here too. It does not apply source_major / specialty as an allow-list, because allowed_domains is a hard whitelist that would gut recall (and the file itself calls those "a preferred list, not an exclusive one").
