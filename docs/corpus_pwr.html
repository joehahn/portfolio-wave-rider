Forward news retriever

The frozen live-news archive (data/forward_corpus/). Two feeds fill it: a daily WebSearch pull (news_pull.sh each evening) plus a one-time GKG+Wayback cold-start seed — the very same BigQuery-GKG discovery + Wayback-lede (+ title-gated live fallback) pipeline the backtest Retriever DB uses, pointed at the last few weeks so the curator has a full trailing window on day one. Store-broad and deduped: each pull appends only genuinely new articles. This is the forward analog of that backtest DB; the curator reads a trailing 21-day slice of it at each review.

Note on sources: the forward pull honors all three news_sources.md tiers, reaching parity with the backtest's source handling.
